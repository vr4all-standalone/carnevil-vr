# CarnEvil VR banner artwork

The header uses a crop of the original **Midway CarnEvil arcade promotional flyer**, combined with the dark grid, bold title, VR badge and platform line used by the other VR4ALL game headers.

Original game artwork: © Midway Games, 1998. The source is the [original flyer scan on LaunchBox](https://gamesdb.launchbox-app.com/games/images/11698-carnevil), [direct scan](https://images.launchbox-app.com/a3321205-c6d9-4afe-a9fc-72929c79d145.jpg).

The game artwork is cropped and scaled; characters and scenery are not AI-generated. This is promotional art, not a headset screenshot. Banner dimensions: 2172 × 724 pixels.
